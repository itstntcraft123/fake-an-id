# Credits for Data

first_names.json: <archive.ics.uci.edu/dataset/591/gender+by+name>, CC BY 4.0 license. AI was used to convert the CSV source to JSON and process names into groups by gender.

last_names.json: <www.census.gov/topics/population/genealogy/data/2020_names.html>. AI was used to convert the Excel source to JSON.

addresses.json: <github.com/EthanRBrown/rrad>, public domain. AI was not used to process this source.

age_groups.json: <www.fhwa.dot.gov/policyinformation/statistics/2023/dl20.cfm>. AI was used to convert the Excel source to JSON and remove unnecessary rows. (The preview table at the website looks different because it is rounded from the downloaded Excel source.)
